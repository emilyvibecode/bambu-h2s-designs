# Pegboard Design 1

A slanted pegboard key hook with a thicker rounded attachment and a lower locating pin. This is the V4 design, named Pegboard Design 1 for the public design collection.

![Shape and installation](preview.png)

## Print files

- [Bambu Studio project](pegboard-design-1-H2S-PLA-Wood.3mf): H2S, 0.4 mm nozzle, Textured PEI, Bambu PLA Wood.
- [STL](pegboard-design-1.stl): geometry only.
- [OpenSCAD source](pegboard-design-1.scad): editable geometry.
- [Instructions](PRINT-INSTRUCTIONS.txt): printing, installation and fit testing.

## Dimensions

| Feature | Dimension |
| --- | --- |
| Upper rounded peg diameter | 4.8 mm before flat-face clipping |
| Tapered terminal diameter | 3.4 mm before flat-face clipping |
| Terminal angle above rearward horizontal | 45 degrees |
| Centerline blend radius | 3 mm |
| Neck distance to start of bend | 6.7 mm |
| Lower locating pin diameter | 5.6 mm before flat-face clipping |
| Lower pin reach | 4.8 mm |
| Vertical hole spacing | 25.4 mm |
| Front projection | 18.2 mm |
| Body print depth | Approximately 4.4 mm |

Designed for a nominal 6.35 mm thick board with 6.35 mm round holes. The simulated board is slightly thicker at 6.55 mm, with slightly smaller 6.25 mm holes. Use at least 8 mm of clear space behind the board. The pin should reduce swivel; commercial cam-lock behavior and load strength have not been demonstrated.

See [research](research.json), [geometry checks](geometry-and-motion-check.json), and [slice results](slice-result.json). Fit must be checked on the actual board before using this attachment for an AirGradient holder.
